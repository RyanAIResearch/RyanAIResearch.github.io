OpenFold3 · NVIDIA H100 80GB · single GPU

Custom triangle kernels that train OpenFold3 faster, and learn the same thing.

StableFold replaces the triangle-attention and triangle-multiplicative path in OpenFold3. Measured against three production backends across three crop sizes at 400 training steps each — twelve complete runs on one H100.

Power

Board power draw

The harness samples the GPU with nvidia-smi every 10 seconds for the whole of each run. Below is that log plotted as recorded — every sample, no smoothing, no fitting. Hover a curve for the reading at that moment.

Each curve starts when its own process starts, so the horizontal extent is the run length — StableFold's line stops first. Draw swings by hundreds of watts inside a single training step, which is why the traces read as bands rather than lines; that texture is the measurement, not noise added in plotting.

Numerical parity

The loss curves land on top of each other

A faster kernel is only useful if the model still trains the same way. All four backends ran from an identical seed and dataset order, so their loss trajectories should agree to within run-to-run noise. Hover a chart to read every backend at that step.
